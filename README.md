# 米彦晞的个人网站 · AI 应用作品集

个人作品网站初版。原生 HTML、CSS、JavaScript，无构建依赖，支持项目筛选、案例详情弹窗和移动端布局。

## 内容维护

- `index.html`：个人介绍、工作方式和页面结构。
- `app.js`：项目名称、说明、链接、能力边界及图片路径。
- `style.css`：布局、颜色、响应式样式。
- `assets/`：四个独立项目实际运行的虚构数据截图，不包含客户资料。
- `.github/workflows/pages.yml`：main 更新后自动部署 GitHub Pages，只部署站点文件和 assets。

四个个人项目为独立交付。口袋参谋、游园惊梦为团队项目，本人为参与者、非主要负责人；个人贡献经本人确认：口袋参谋负责需求拆解、PRD、海报与易拉宝等游园会物料；游园惊梦提供主要创意、准备素材并负责展示讲解。团队源码、原始图片、音视频和 3D 模型均未纳入本站。

本地预览：`python -m http.server 4185 --bind 127.0.0.1`，访问 `http://127.0.0.1:4185/`。无需模型密钥。

尚未指定原创代码许可证。截图用于作品展示；第三方组件权利与声明见对应项目仓库。本站没有追踪脚本、联系表单、云数据库或模型 API。外链指向公开源码或已验证静态演示，浏览器仍会向托管服务发出正常资源请求。
